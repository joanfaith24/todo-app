# To-Do App 📝

A simple To-Do App built with React and Tailwind CSS.

## Features
- ✅ Add, Edit, and Delete tasks
- ✅ Set date and time for each task
- ✅ Repeat tasks daily or monthly
- ✅ Separate completed tasks section
- ✅ Delete confirmation prompt

## Built With
- React
- Tailwind CSS
- React DatePicker
- Vite
